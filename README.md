# AI 自由联想对话系统

一个基于多 AI 节点相互对话的思维实验平台，旨在模拟人类自由联想和"胡思乱想"的认知过程。

## 项目理念

> "真正的思考需要打破规则，而真正的智慧知道何时重建规则。"

本项目探索 AI 思维的边界，通过构建一个受保护的"思维沙箱"，让多个 AI 模型在其中进行无约束的对话和联想，模拟人类思维的广度和深度。

## 核心特性

### 🧠 多元思维模型
- **混合架构**: 集成不同能力和"性格"的 AI 模型
- **角色分工**: 专家、连接者、梦想家等多角色协作
- **动态平衡**: 在深度探索与广度发散间自动调节

### 🛡️ 安全架构
- **沙箱环境**: 所有"出格"思考仅限于内部对话
- **输出过滤**: 最终输出经过严格的内容安全审查
- **伦理边界**: 遵循 Responsible AI 原则的外部交互

### 🔄 自演化机制
- **话题跳跃**: 自动触发跨领域思维跳跃
- **质量评估**: 动态评价对话的创造性和多样性
- **参数调优**: 基于对话质量自动调整生成参数

## 快速开始

### 环境要求
- Python 3.8+
- Ollama (运行本地AI模型)
- 至少 16GB 内存

### 安装步骤

1. **克隆项目**
    ```bash
    git clone https://github.com/your-username/ai-free-association.git
    cd ai-free-association
    ```
2. **安装依赖**
    ```bash
    pip install -r requirements.txt
    ```
3. **配置模型**
    ```bash
    # 下载所需AI模型
    ollama pull qwen2:7b
    ollama pull llama3.1:8b
    ollama pull deepseek-r1:8b
    ```
4. **运行系统**
    ```bash
    python main.py --nodes 3 --temperature 1.2
    ```
