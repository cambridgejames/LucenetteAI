# 代码风格规范

> 📌 初稿：仅记录现有原型代码已体现的约定。完整规范细化讨论后定稿，所有实现代码以本规范为准。

## 已确立的约定（继承自原型代码）

1. Python 3.12+，全程类型注解（函数签名与属性声明）；
2. 模块分层：`python/cbb`（通用基础）/ `python/chat`（对话）/ `python/config`（配置）/ `python/tools`（能力插件），新模块按层归属；
3. 可序列化协议：数据类实现 `Serializable`（`to_dict`），经 `JsonUtil.to_json` 统一序列化；
4. 日志：统一使用 `cbb.Logger.get_file_logger`，业务代码禁止裸 print（CLI 输出除外）；
5. 标识符与注释使用英文，文档使用中文。
