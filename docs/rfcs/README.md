# RFC 提案流程

本项目设计先行：所有新想法先写一页提案再动工，避免方向性返工。这也正是本项目的许愿传统——欢迎把愿望写成 RFC。

## 提案模板

```markdown
# RFC-XXXX：标题

## 动机
要解决什么问题？为什么现在做？

## 方案
核心设计思路，附必要的图与数据模型。

## 接口影响
影响哪些契约（docs/01-contracts/）与模块（docs/02-modules/）？

## 验收标准
怎么算做成了？
```

## 流程

1. 在本目录新建 `RFC-XXXX-标题.md`（编号顺延），发起讨论；
2. 讨论收敛后由维护者裁决：采纳（进入工作包看板）/ 搁置 / 拒绝；
3. 采纳的重大架构决策同步记录到 [docs/00-global/adr/](../00-global/adr/)。
